# NM DEV — Сайт студии разработки

Сайт-портфолио студии NM DEV: мобильные приложения, Telegram-боты, веб-сайты.

## 🛠 Технологии

- **HTML5** — семантическая вёрстка
- **CSS3** — Grid, Flexbox, CSS-переменные, адаптив
- **Vanilla JS** — без фреймворков, ES6+
- **SEO** — meta-теги, Open Graph, JSON-LD, sitemap
- **i18n** — 3 языка (RU / KG / EN), localStorage
